# FreeBooks Core v4.3.0 — Admin Operations, Analytics & Integrations

## Included
- Date-scoped operational summary for donation records.
- Donation status breakdown and daily submission activity.
- Catalogue published/draft counts.
- WooCommerce order count and gross order totals when WooCommerce is active.
- Integration readiness panel for WooCommerce, public contact details, Next.js URL/revalidation configuration, email transport hooks, scheduled monitoring and payment gateway availability.
- CSV export of date-scoped donation and catalogue metrics.
- Administrator-only REST endpoint: `GET /wp-json/freebooks/v1/admin/operations-summary?from=YYYY-MM-DD&to=YYYY-MM-DD`.

## Admin navigation
Open **FreeBooks → Operations & analytics** in WordPress admin.

## Data and privacy
This release reuses existing WordPress donation and catalogue records and WooCommerce orders. It does not create duplicate records or new database tables. The analytics REST route requires an authenticated administrator with `manage_options`. CSV export is nonce-protected and administrator-only.

## Interpretation notes
- Donation and item counts are operational counts.
- WooCommerce gross order totals are not donation revenue or net proceeds; totals may include taxes, shipping and discounts according to store configuration.
- A detected configuration is not proof of live delivery or successful transactions.
- Payment gateways, SMTP, carrier connections and Next.js revalidation still require end-to-end testing in their respective provider environments.
- The dashboard does not initiate payments, create shipments or send customer communications.

## Upgrade
Back up the WordPress database and `wp-content`, then upload this ZIP over the existing **FreeBooks Core** plugin. No destructive migration is included.
