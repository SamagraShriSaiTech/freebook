# FreeBooks Core v5.3.0 — Privacy Centre

## Included
- Authenticated `POST /wp-json/freebooks/v1/account/privacy-request`.
- Request types: `access` and `deletion`.
- Requests are stored as private `fb_privacy_request` records with a reference, account ID, email, submitted time and pending/reviewed status.
- Duplicate pending requests of the same type for the same account are rejected.
- Admin queue is available under FreeBooks → Privacy & data rights.
- Admin can mark a request reviewed. This does not itself export or erase data.
- Existing WordPress personal-data exporters/erasers and WooCommerce privacy tools remain in place.

## Safeguards
- Account authentication uses the existing opaque bearer token.
- Account deletion is request-only; no automatic account deletion is performed.
- Staff must verify identity, assess legal/operational retention, process export/erasure through the relevant tools and document the result.
- Donation item/status history may be retained with direct donor identifiers anonymised by the existing eraser.

## Compatibility
- Public frontend v2.3.0.
- No database migration is required; WordPress stores requests as private posts and metadata.
