# FreeBooks Core v4.6.0 — Donation tracking and donor portal

Adds public REST endpoints for OTP-verified donor access:

- `POST /wp-json/freebooks/v1/donations/portal/request-otp` with JSON `reference`, `email`, `phone`.
- `POST /wp-json/freebooks/v1/donations/portal/verify-otp` with JSON `reference`, `email`, `phone`, `otp`.
- `GET /wp-json/freebooks/v1/donations/portal/{reference}` with `X-FreeBooks-Portal-Token` header.

Codes are hashed at rest, expire after 10 minutes, resend cooldown is 60 seconds, and OTP attempts are limited to five per code. Verification tokens are random, stored only as hashes, and expire after 30 minutes. The request endpoint uses a generic response to reduce reference enumeration. Existing shortcode tracking and legacy REST routes remain compatible.

Donor portal data is restricted to the verified donation: reference, current status, item title/category/quantity, update time and status timeline. Donor contact details, staff-only notes, payment data and internal records are not returned. Email delivery depends on the site's configured WordPress mail transport.
