# FreeBooks Core v5.0.0 — Shopping Cart & Checkout

## Purpose
Adds a minimal public checkout metadata endpoint for the headless Next.js storefront. WooCommerce remains authoritative for cart sessions, products, stock, tax, shipping, order creation and payment processing.

## REST endpoint
`GET /wp-json/freebooks/v1/checkout/payment-methods` returns only enabled and currently available WooCommerce gateways as `{ id, title, description }`. It does not expose gateway settings, credentials, API keys or private configuration.

## Store API
The frontend calls the WooCommerce Store API through an allow-listed Next.js proxy. The proxy uses the opaque `Cart-Token` returned by WooCommerce and stores it in an HttpOnly, SameSite=Lax cookie scoped to the frontend origin. It does not store card data or payment credentials.

## Stock and single-copy items
WooCommerce continues to own inventory and stock reservations. Existing catalogue sync configures stock management and marks one-copy products as sold individually. Checkout revalidates stock and totals on the server.

## Configuration
Configure payment gateways, shipping zones/rates, tax and coupons in WooCommerce. Only gateways that WooCommerce reports as available are exposed. Gateway-specific `payment_data` requirements depend on the selected gateway's Store API compatibility; configure and test those integrations before enabling production payments. COD is not enabled by this module and is only offered if an administrator explicitly enables a compatible gateway.

## No destructive migration
No database tables, options or existing records are changed by this module.
