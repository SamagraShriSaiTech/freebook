# FreeBooks Core v4.4.0 — Security, Privacy, Accessibility & Launch Hardening

## Included
- Administrator-only launch hardening dashboard at **FreeBooks → Launch hardening**.
- Manual launch checklist for backups/restore, administrator MFA, HTTPS, patching, dashboard file editor, privacy policy, retention schedule, consent, keyboard/content/visual accessibility, payment/email/shipping tests and incident ownership.
- Checklist completion is saved as an administrator attestation and recorded in the existing audit log. It does not claim automated verification.
- Basic environment diagnostics for PHP/WordPress baselines, HTTPS, database connectivity, public debug display, `DISALLOW_FILE_EDIT`, FreeBooks security-header setting, privacy policy assignment and frontend URL.
- Administrator-only REST diagnostics: `GET /wp-json/freebooks/v1/admin/launch-hardening`.
- Adds HSTS only on HTTPS requests, plus `X-Permitted-Cross-Domain-Policies: none` to the existing security response headers.
- Adds visible keyboard focus and reduced-motion support to WordPress-rendered FreeBooks components.
- Updates integration diagnostics to recognize FreeBooks Core v4.4.0.

## Existing controls retained
- Login and public form rate limiting, hashed security event logs, optional XML-RPC disablement.
- WordPress personal data export/erasure integration.
- Donation audit log, CMS noindex ownership, monitoring and Site Health integration.

## Admin navigation
Open **FreeBooks → Launch hardening** in WordPress admin. The page is restricted to users with `manage_options`.

## Important limitations
- The checklist is not a legal compliance certification, penetration test, WCAG certification or proof of backup restoration.
- The privacy retention schedule and policy must be approved and implemented by the Foundation; this release does not automatically delete user records.
- The keyboard/contrast/alt-text/accessibility review for the public Next.js frontend must be completed against the deployed frontend.
- HSTS is emitted only when WordPress detects HTTPS. Confirm proxy/SSL configuration before relying on it.
- Payment, SMTP and carrier checks remain real end-to-end acceptance tasks.

## Upgrade
Back up the WordPress database and `wp-content`, then upload this ZIP over the existing **FreeBooks Core** plugin. No destructive database migration or new database table is included.
