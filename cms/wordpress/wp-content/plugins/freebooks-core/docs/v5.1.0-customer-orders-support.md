# FreeBooks Core v5.1.0 — Customer Orders & After-Sales Support

## Customer REST endpoints
- `GET /wp-json/freebooks/v1/account/order-detail?id={order_id}` — requires the FreeBooks account bearer token; returns only an order belonging to the authenticated customer, line items, order state and public fulfilment metadata.
- `POST /wp-json/freebooks/v1/account/order-support` — requires the same token and an owned order ID; creates a private customer support case with a generated reference.

## Security
- Order ownership is checked against the WooCommerce customer ID. For guest orders, billing email must match the authenticated account email.
- No order lookup by unauthenticated ID is exposed.
- Case content and evidence are private to staff; customer detail responses expose only case reference, type, date and status.
- The API validates issue type, reason, item name against order line items, quantity, message length and requested amount against the order total.

## Operational rules
- Return/refund requests are requests only; approval is not automatic.
- Actual refunds remain processed in WooCommerce and through the configured payment gateway.
- Shipment booking, carrier labels, parcel scans and carrier tracking remain with the configured carrier plugin. FreeBooks only displays staff-entered carrier/tracking details.
- No destructive database migration or new database tables.
