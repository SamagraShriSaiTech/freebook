# FreeBooks Core v5.2.0 — Newsletter REST Signup

## Endpoint
`POST /wp-json/freebooks/v1/newsletter/subscribe` accepts `email`, `consent` and a honeypot `website` field. The endpoint validates email and explicit consent, applies a short email-hash transient throttle, checks existing private subscriber records, and creates a private subscriber record.

## Privacy and security
- The subscriber email is stored in the existing private `fbem_subscriber` post type.
- Consent and consent timestamp/source are recorded. No IP address is stored.
- A signed WordPress-hash unsubscribe token is generated; only its hash is stored. The raw token is sent in the unsubscribe email and never returned to the browser.
- The endpoint returns a generic response for existing subscribers to reduce account/list enumeration.
- Email delivery failure removes the newly created subscriber record and returns an error.

## No migration
Uses the existing subscriber post type and metadata; no new database tables or destructive migration.
