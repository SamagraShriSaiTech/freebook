# FreeBooks Core v4.5.0 — Public Donation API

This cumulative update adds `POST /wp-json/freebooks/v1/donations/submit` for the public Next.js donation experience.

- Accepts a JSON `payload` multipart field and up to 3 photo files named `fb_photos[]`.
- Accepts up to 20 item groups.
- Requires donor name, valid email, phone, items and consent.
- Supports city, preferred contact, marketing opt-in, handover preference, message and optional campaign ID.
- Photos: JPG/JPEG, PNG or WebP, maximum 5 MB each.
- Uses a honeypot, optional configured Cloudflare Turnstile verification, duplicate detection, existing governance submission guard and an additional IP rate limit.
- Stores the donation through the existing `FB_Donations::create()` workflow. Existing admin review queue and notification workflow remain authoritative.
- Returns only donation reference and submitted status.
- The public frontend config exposes the Turnstile site key only when both site and secret keys are configured. The secret is never exposed.

The existing JSON `POST /donations` endpoint remains for compatibility. The new multipart endpoint is intended for the Next.js public donation form.
