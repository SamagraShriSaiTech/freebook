# FreeBooks Core v3.8.0 — Catalogue Discovery & Search

## Included
- Expanded catalogue metadata: subtitle, edition, publication year, pages, format, series and subject.
- Storefront filters for author, ISBN, publisher, format and price range.
- Most-viewed sort and deduplicated daily catalogue view counts.
- Recently viewed book cookie and `[freebooks_recently_viewed]` shortcode.
- Category-based recommendations and `[freebooks_recommended_books]` shortcode.
- Search-term and zero-result analytics (up to 500 distinct search groups).
- Admin report at **Book Catalogue → Discovery analytics**, with CSV export.
- Public REST search endpoints:
  - `GET /wp-json/freebooks/v1/catalogue/search?q=biology&limit=10`
  - `GET /wp-json/freebooks/v1/catalogue/isbn/9780000000000`

## Shortcodes
- `[freebooks_recently_viewed]`
- `[freebooks_recently_viewed limit="6"]`
- `[freebooks_recommended_books]`
- `[freebooks_recommended_books current_id="123" limit="4"]`

## Metadata entry
Edit a catalogue item and use the FreeBooks inventory details panel to populate edition, year, pages, format, subtitle, series and subject. Keep ISBN accurate; the ISBN endpoint searches existing catalogue data and does not automatically fetch metadata from third-party services.

## Privacy and performance notes
- Recently viewed state is stored in first-party browser cookies for up to 30 days.
- A short-lived visitor cookie is used to avoid repeatedly increasing view counts from the same browser.
- Search analytics retain up to 500 distinct search groups and store the entered search phrase. Do not ask visitors to enter personal information in search. Include this processing in the privacy notice and retention review.
- The discovery REST endpoints expose published catalogue fields only.
- Search analytics are operational signals, not proof of demand.
- No external ISBN lookup provider or paid API is required.

## Release validation
PHP lint and ZIP integrity checks are run during packaging. This release has not been live-tested against the user's WordPress/WooCommerce environment. Run the full combined acceptance suite after all modules are installed.
