# FreeBooks Core v4.8.0 — Membership, Loyalty & Community

## Included
- Member membership summary endpoint with recognition level and participation ledger.
- Reading-interest preferences stored on the authenticated WordPress user.
- Member-only book request submission and request history.
- Public, admin-moderated Community Updates content type and read endpoint.
- Recognition points for completed WooCommerce purchases (1 point per 100 store-currency units, minimum 1) and accepted volunteer applications (25 points, once per application).
- Recognition levels: Reader (0–99), Active Reader (100–499), Community Champion (500+).
- Admin Membership Overview page.

## REST endpoints
All endpoints are under `/wp-json/freebooks/v1`.
- `GET /membership/me` — authenticated member summary, points ledger and own book requests.
- `POST /membership/profile` — authenticated reading interests and short reading bio.
- `GET /membership/book-requests` — authenticated member's own requests.
- `POST /membership/book-requests` — authenticated member creates a book request.
- `GET /community/updates?per_page=8` — public published community updates.

Authenticated endpoints use the existing FreeBooks account bearer token. The Next.js frontend proxy reads the HttpOnly `fb_account` cookie; the token is not exposed to browser JavaScript.

## Points policy
Points are non-cash, non-transferable participation indicators. They are not money, store credit, discounts, a donation receipt, a tax benefit or a promise of a reward. Purchase points are recorded only after WooCommerce marks an order completed. Each order is idempotently recorded by order ID. Volunteer recognition is recorded once when an application reaches accepted status and its email matches a FreeBooks account.

## Admin workflow
- Publish and moderate Community Updates under WordPress → Community Updates.
- Review requests under WordPress → Book Requests (existing request workflow).
- View point totals and levels under Community Updates → Membership Overview.

## Compatibility and deployment
Cumulative update from FreeBooks Core v4.7.0. No new database tables and no destructive migrations. User meta and existing book-request post type are reused. Keep WooCommerce enabled for purchase recognition. Existing donation tracking and customer account features remain available.

## Verification
PHP syntax lint and ZIP integrity checks should be run before installation. Test actual WooCommerce order completion, accepted volunteer application, member token access and public updates on the target WordPress site. No cash redemption or monetary donation feature is introduced.
