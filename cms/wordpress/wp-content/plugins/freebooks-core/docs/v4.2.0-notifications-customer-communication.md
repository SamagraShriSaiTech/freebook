# FreeBooks Core v4.2.0 — Notifications & Customer Communication

## Included
- Customer email preferences shortcode: `[freebooks_notification_preferences]`.
- Logged-in customer REST API:
  - `GET /wp-json/freebooks/v1/customer/notification-preferences`
  - `POST /wp-json/freebooks/v1/customer/notification-preferences` with JSON booleans `order_updates`, `donation_updates`, and/or `community_updates`.
- Donation status emails are suppressed for registered donors who turn off donation updates. Guest donors retain the existing operational email behavior because no account preference is available.
- Optional staff-triggered fulfilment status emails respect a registered customer's order-update preference. WooCommerce's essential order/payment/account messages remain under WooCommerce control.
- Branded WooCommerce email sender name and footer text.
- Admin notification centre records recent WordPress mail hand-offs/failures with timestamp, subject, recipient count and one-way recipient fingerprints. Message bodies and plain email addresses are not stored in this log.
- Existing donor communication history and resend controls remain available.

## Consent and delivery boundaries
- Community updates preference is stored separately; it does not subscribe anyone to the newsletter. Newsletter consent and unsubscribe continue to use the newsletter system's own controls.
- Essential account, payment, security and legally required messages may still be sent even if optional preferences are disabled.
- “Handed off” means WordPress accepted a message for sending. It is not proof of inbox delivery. Configure SMTP/transactional email and domain authentication (SPF, DKIM, DMARC), then verify provider delivery/bounce reports.
- No SMS or WhatsApp sending provider is bundled or represented as configured.

## Install
1. Back up the WordPress database and `wp-content`.
2. In WordPress, go to Plugins → Add New Plugin → Upload Plugin and upload the v4.2.0 ZIP.
3. Choose Replace current with uploaded, then activate/update FreeBooks Core.
4. Add `[freebooks_notification_preferences]` to the customer account/preferences page.
5. Configure SMTP and test messages during the final combined acceptance test.

No new database tables or destructive migrations are introduced. Preferences use user meta; mail events use a capped WordPress option.
